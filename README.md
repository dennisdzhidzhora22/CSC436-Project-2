# Project Name: PC Builder

## Description:
This is a page that allows users to pick out parts to build a PC with, then shows some useful data based on the selection, such as total wattage, total price, and any compatibility issues detected with the user's selected parts.

## How to run:
With a terminal opened in this directory, run `npm install` followed by `npm run dev`, then open the given localhost link in a browser.
